# Security policy

Report vulnerabilities privately through GitHub: **Security -> Report a vulnerability** on this repository (do not open a public issue, and never include real personal or medical data).
The prioritised review, controls and known limitations are in [docs/SECURITY.md](docs/SECURITY.md). This project handles health-adjacent data: do not run it with real patient or donor data
before the deployment blockers in [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) are closed and a legal/privacy review is done.
